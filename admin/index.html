دخول

اكتب كلمة السر اللي حطيتها في ADMIN_KEY على Vercel. هتفضل مسجّل دخول على الجهاز ده لمدة أسبوع.

تعديل الموقع لسه مش متوصّل

محتاج مفتاح GitHub في Vercel باسم GITHUB_TOKEN (صلاحية Contents: Read and write على ريبو الموقع بس)، وبعدين Redeploy.

لسه الإحصائيات مش متوصّلة

على Vercel: اربط قاعدة بيانات Redis بالمشروع (Storage)، وضيف متغير ADMIN_KEY في Settings ← Environment Variables، وبعدين اعمل Redeploy.
